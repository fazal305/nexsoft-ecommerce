# NexMart — Full Stack E-commerce Website

A full stack e-commerce website built for the Nexsoft Solutions internship.

## Features

- Product listing page
- Product detail page
- Shopping cart functionality
- User authentication with JWT
- Customer and admin authorization
- Simulated payment checkout
- Customer order history
- Admin dashboard
- Admin product management
- Admin order management
- Admin customer management

## Tech Stack

### Frontend
- HTML5
- CSS3
- Bootstrap 5
- jQuery
- Vanilla JavaScript

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- bcryptjs
